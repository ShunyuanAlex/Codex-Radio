Codex Radio 0.12.0 · 本地 Codex 菜单栏工具
Apple Silicon 与 Intel 通用二进制 / macOS 13+。Intel 已交叉编译，尚未完成 Intel 实机验收。

使用
启动Codex Radio.app，点击屏幕顶部“Radio”展开面板。首次使用默认静音、音量18%；音量会保存，通用设置可开启“启动后自动启用播报”。
显示最近7天使用过的本地 Codex 项目及真实对话标题，含一周内已归档的对话。独立对话单独成组。
项目拥有真人呼号（Alpha、Bravo 等），项目内对话使用固定数字编号，例如 Alpha 1、Alpha 2。
点击菜单栏控制按钮打开独立设置窗口，左侧分为通用、声音与模式、呼号分配、接入与权限。项目右侧更改字母呼号；对话行输入0–9999并按回车或保存。
字母呼号或同项目数字已被占用时自动互换，保持唯一。编号和选择保存在本机，刷新、改标题、重启不重排；0.5旧编号自动保留。
每60秒及打开面板时自动刷新，亦可点击“刷新”。刷新目录不会回放历史声音，也不推断对话当前活动状态。
子代理合并到父对话，使用父对话的同一呼号，不单独列出。
首次新事件前显示“等待新的实时事件”；尚未收到实时活动的对话显示待命，不猜测此前状态。
确认听音环境后点击“启用播报”。先播真人项目呼号和数字，无额外间隔接状态提示音，使用同一条 PCM 音轨。
模式按“专注、详细、自定义”排列；初次升级默认专注，之后记住用户选择。
专注只听完成/本轮收尾、等待确认、停止和报错，不播报发送/插入、处理中、工具返回。
详细模式逐条顺序播放全部接入的状态，不合并、不按3秒过期；忙时显示待播数量。静音、停止播报或切换模式会清空队列。
自定义模式在独立窗口“声音与模式”页勾选八种实际状态，支持全部取消；勾选结果保存。
“插入”仅在 Codex 为该操作发出 UserPromptSubmit 时有声；当前正式 Hooks 无独立插入事件，无法区分发送与插入。
工具返回不等于任务成功；原“未知结果”改为“工具已返回”并配独立回执声。只有明确工具错误才显示工具报错。
专注/自定义：普通事件300ms合并，高优先级抢占，队列最多8条、过期3秒。详细模式不执行这些合并和过期规则。所有模式单声道串行，不重叠播放。
“停止播报”和“静音”清空声音与队列，只控制Codex Radio，不停止 Codex 对话。退出后不播报；“登录时自动启动”可在通用设置中开关。
菜单弹窗按当前提示、播报开关与音量、收听声音与模式包、最近活动分区。齿轮集中打开设置；更多菜单包含连接/断开和退出。停止按钮仅在播报或有队列时可用。完整项目列表位于独立设置窗口。
“声音与模式”提供自定义勾选、音源导入和试听。试听不改变实际对话状态，可导入自备音频，播放最多3秒。

真人呼号录音
采用公开录音 NATO_Phonetic_Alphabet_reading.ogg。
来源：NATO Phonetic Alphabet reading，valeatory，2014-02-28，作者使用 Audacity 自己录制。
https://commons.wikimedia.org/wiki/File:NATO_Phonetic_Alphabet_reading.ogg
CC BY-SA 3.0：https://creativecommons.org/licenses/by-sa/3.0/
改动：离线转为24kHz单声道PCM，切分26个字母呼号和10个数字；按 -52dBFS / 5ms RMS 窗检测首尾，保留8ms前后余量，调整峰值、2ms端点淡化；Alfa 去除发音结束后分离的低频长尾。
录音末尾数字顺序为0、1、2…9。字母与数字之间不增加空白，相邻人声使用12ms线性叠化；人声到状态音不叠化，状态音内部节奏不变，没有改变词内发音或语速。两位以上对话编号逐位读，例如12读作“一、二”的原录音数字。
保留原声线、发音与词内速度，没有语音合成或声音克隆。处理片段仍按 CC BY-SA 3.0 提供。
切点、时长和 SHA256 见 HookReview/voice-catalog.json。已验证离线解码和波形；不代表实体听音验收。

航空提示音：两款内置声音包
在设置 → 声音与模式 → 声音包，选择“B777”“A320”或“歼-11A”。首次使用 A320；选择立即保存，重启继续使用。切换会停止当前音轨、清空待播队列，下一条事件使用新包。个人导入音源仍优先，点该行“还原”恢复当前包。
八类固定标识：发送/插入＝短按键；处理中＝单声短铃；工具返回＝双按键回执；压缩上下文＝高低收束音；本轮收尾＝完整双钟声；等待确认＝间隔双提醒；已停止＝断开提示（空客单声电子提示、波音保留原断开声）；工具报错＝连续三连告警。
每款均包含8段独立PCM音效。保持两款的类别含义一致，同时保留机型素材的音色差异。仅单次提示，不循环警报。

另一台 Mac 首次启动
1. 先安装并登录 Codex。将 DMG 中的 Codex Radio.app 拖到 Applications 后从该处启动；不要直接从 DMG 运行。
2. 当前发行包使用 ad-hoc 签名，未进行 Apple 公证。另一台 Mac 可能拦截启动：确认应用来源后，按 Apple 官方说明在尝试打开之后前往“系统设置 → 隐私与安全 → 仍要打开”。Radio 不会关闭 Gatekeeper，也不会移除隔离属性。
   https://support.apple.com/en-us/102445
3. Radio 首次启动打开“接入与权限”。确认 Codex 数据目录（默认 ~/.codex；自定义 CODEX_HOME 可选择），阅读范围后点击“允许读取并安装接入”。目录不存在时先打开 Codex，或选择实际目录。目录／JSON 无效时停止并显示错误，不覆盖现有文件。
4. 内置原生程序安装在当前用户 Application Support/WingRadio，向所选 hooks.json 追加缺少的12项 Radio Hooks，并备份已有配置。无需 Python、Homebrew、Xcode、管理员口令或额外账户。Codex 自身登录仍由 Codex 处理，Radio 不读取其凭据。
5. 安装配置不等于 Codex 授权。点击“复制 CLI 启动命令”，在终端粘贴运行，再输入 /hooks；逐项审查并信任 Radio 的12项定义。如果当前 Codex 桌面版提供 Hooks 审查入口，也可在该处完成。Radio 不执行这一步，不写信任数据库，不修改 config.toml 或降低 Codex 权限。
   https://learn.chatgpt.com/docs/hooks
6. 重新打开需要接入的本地对话并发送一句话。Radio 显示本次启动已收到真实事件，才算此接入路径验证通过；手动试听不计入。然后在菜单栏“启用播报”。默认静音启动；通用设置可以开启自动播报，使用保存的音量与模式。
7. 若一直等待：确认使用同一个 Codex 数据目录、12项已信任、会话已重新打开。用户或管理员可能禁用 Hooks；Radio 不绕过此限制。云端、远程和部分托管工具不保证覆盖。

权限与隐私
Radio 不申请辅助功能、屏幕录制、麦克风或完整磁盘访问权限。首次允许后，只读项目、对话标题、归属、时间、归档状态等本地元数据；不打开 transcript、聊天正文或凭据。
事件收集器仅写入事件类型、必要关联ID及明确结果；不保存聊天内容、工具参数或原始结果。目录0700、事件文件0600，原子落盘，只清理超过60秒的自身事件。原生程序不联网、不播音、不批准／拒绝 Codex 操作，标准输出始终为空对象。
目录读取采用当前 Codex 版本的本地元数据格式，并非稳定公开API；格式不兼容时显示错误。登录启动默认关闭，用户可在通用设置中启用；使用macOS SMAppService.mainApp，不添加自制LaunchAgent或后台守护进程。

接入与更新
已配置旧12项的电脑继续使用原 Python 收集器和逐字节相同的 Hooks，不会因应用更新强制更换接入程序或重置信任。旧环境原 Python 依赖保留；“无需Python”指0.9.0的新原生安装。
只完成旧10项的电脑可在“接入与权限”补齐 PreCompact / PostCompact，新增项仍需用户审查信任。新原生安装将程序放在带内容哈希的固定路径，应用更新不会静默替换已信任命令。
默认安装位置：/Applications/Codex Radio.app；用户级接入：~/Library/Application Support/WingRadio；默认Hooks：~/.codex/hooks.json。
早期安装可能位于 ~/Applications/Codex Radio.app。升级时退出并替换原位置，避免保留两份运行中的应用。

0.10.0 飞机面板与启动设置
设置按通用、声音与模式、呼号分配、接入与权限分为四页。通用集中输出、启动和菜单栏外观；声音页提供机型、收听模式和八类提示，导入／还原收进单项菜单；呼号页按项目折叠，搜索时展开结果。全部开关保留中文名称、状态与键盘操作。
“登录时自动启动”调用macOS13+官方SMAppService.mainApp注册／注销，读取系统实际状态。等待系统允许时独立显示WAIT并提供“打开系统登录项”；失败显示错误，不虚报成功。仅安装在/Applications或个人~/Applications的应用可开启；临时构建与DMG不可注册。登录启动不主动弹出正常面板；尚未完成接入时显示引导。
“启动后自动启用播报”单独保存，默认关闭。开启后下次启动使用保存的音量与模式；仅已允许读取、12项配置完整、呼号录音有效时自动启用，未完成接入继续静音。更改此开关不直接改变当前播报状态。当前静音、停止、模式筛选及队列规则保持原行为，不回放启动前事件。
音量保存范围0–50%，无设置时18%，无效非有限值回退18%。新开关默认关闭，升级不擅自注册登录项或自动播报。
官方API说明：https://developer.apple.com/documentation/servicemanagement/smappservice
自动检查不注册真实登录项；实际系统注册状态、注销与重启恢复另外核对。测试与本机验证不等于另一台Mac、用户注销／重登录或Intel实机验收。
